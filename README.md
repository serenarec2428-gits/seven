### Project Description

**TinkerUseless** is a computer-vision-based project developed as part of the **TinkerHub Useless Project**.

The project uses a camera and **OpenCV** to capture and process images in real time. The Python program analyzes the camera input, detects objects/shapes, and classifies them using image-processing techniques.

The project was developed using **Visual Studio Code**, **Python**, and **OpenCV**.

---

### The Problem (that doesn't exist)

Have you ever looked at an object and thought:

> "I wonder what shape this is?"

Probably not.

Humans are perfectly capable of recognizing basic shapes without any technological assistance. However, we decided that this extremely unnecessary task deserved a completely unnecessary computer-vision system.

The world clearly needed a machine to spend its valuable processing power answering the most important question of all:

**"Is that a circle, triangle, rectangle, or something else?"**

---

### The Solution (that nobody asked for)

We built **TinkerUseless** — because apparently identifying shapes with our own eyes was too easy.

Using a camera, Python, and OpenCV, our system:

1. Captures the world through a camera.
2. Processes the incoming video in real time.
3. Detects objects and their contours.
4. Analyzes the detected contours.
5. Classifies the detected shape.
6. Displays the result on the screen.

So now, instead of simply looking at an object and knowing what shape it is, we can ask our computer to do it for us.

**Was it necessary? No.**

**Did we build it anyway? Absolutely.**

### Implementation

#### For Software:

The project uses Python and OpenCV for real-time image processing.

The camera captures video frames, which are processed by OpenCV. The program identifies contours from the processed image and analyzes their properties to determine the shape of the detected object.
